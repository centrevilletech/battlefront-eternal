# Original HUD vectors and fonts

**Superseded for gameplay:** the traced atlas loader is no longer
used by the HUD. Tiny glyphs and translucent artwork looked worse after
tracing. `src/raster-hud.js` now loads 4× lossless WebP atlases generated by
`tools/upscale_hud.py`, preserving the source artwork, font metrics and UVs.
Lanczos filtering uses premultiplied alpha to avoid dark fringes. This smooths
the source pixels; it does not recover detail absent from the originals.

Install Pillow in the extraction environment (`python -m pip install Pillow`).
`tools/extract.py` then generates the larger atlases during common-asset intake.
For an existing extraction, run `python tools/upscale_hud.py`. Files stay in
ignored `public/common/raster-hud/`. Without Pillow or generated atlases, the
game retains native raster art. Existing traced SVG files are ignored at runtime.
The fixed 4× size avoids repeated atlas reallocations when resizing the window.

Validation: `python -m unittest discover -s tests -p test_raster_hud.py` and,
with Vite running, `node tests/visual-assets.mjs` (set `PLAYWRIGHT_MODULE` if
Playwright is installed outside the repo).

The following documents the older optional tracing experiment, retained for
reference. The unused browser atlas loader and its browser check have been removed.

`tools/vectorize_hud.py` is an optional post-extraction step. It traces the
original HUD art into SVG paths and bitmap font glyphs into SVG outlines and
TrueType fonts. It never overwrites the source PNGs or original font metrics.
Generated files remain under ignored `public/`, alongside the private retail
extracts; do not commit or distribute them with the source repository.

```sh
python3 -m venv ~/.venvs/battlefront-vectors
~/.venvs/battlefront-vectors/bin/pip install -r tools/requirements-vector-hud.txt
~/.venvs/battlefront-vectors/bin/python tools/vectorize_hud.py --common public/common
```

Run after `tools/extract.py` has produced `common.json`, including its `fonts`
metadata and referenced textures. The converter defaults to nine HUD atlases
and icons plus every font page. `--art name1 name2` changes the artwork list;
`--output path` changes the output directory. The default output folder is `public/common/vector-hud/`; gameplay does not load it.

Outputs:

- `manifest.json`: atlas dimensions, source SHA-256 hashes, original glyph
  advances/rectangles/UVs, and generated font/symbol filenames.
- SVG atlases with the original view boxes. Artwork uses separate color and
  luminance-opacity paths, preserving translucent panels. Font atlases use the
  individual glyph contours at their original UV positions.
- A TTF per font, with original advances scaled to 1024 units per em, plus an
  SVG symbol per glyph. Counters, punctuation and spaces are retained. Extracts
  whose baseline field is zero get an outline-font baseline inferred from
  capital/digit bounds; original metadata is preserved separately.
- `preview.html`: enlarged art and outline-font samples for visual review.

With Vite running, open `/common/vector-hud/preview.html`. Current extracted
assets produce four fonts, each with 226 mapped glyphs. This is outline
reconstruction from raster assets: it cannot recover detail lost in the source.
Fonts use an upsampled alpha contour with polygon fitting to preserve angular
stems; artwork uses spline/color tracing and can approximate tiny gradients or
compressed pixels. Review new imports before treating their output as final art.

The current HUD uses the lossless raster atlas pipeline. These vector masters
remain offline conversion outputs; there is no runtime SVG rasterizer or
display-density refresh path. HUD state, bitmap glyph geometry and layout are
owned by the Rust [battle HUD](hud.md), with imported atlas coordinates retained.

Verification of generated non-retail vector masters uses the Python tests:

```sh
python -m unittest discover -s tests -p 'test_vector_hud.py'
```

These checks cover paths, opacity masks, font counters, advances, original atlas
coordinates and source preservation. Runtime raster atlas IO remains shared
with the shell's interface resource host.
