# Security

Please report vulnerabilities privately, not in a public issue. Use this
repository's private vulnerability reporting (the **Security** tab, then
**Report a vulnerability**). Include the affected version (the version line
from the bottom right of the main menu), what you found and how to
reproduce it.

This repository covers the desktop app, its updater, the multiplayer client
and transport, and the game data tools. The dedicated server, the master
and the relay have their own repositories:

- [battlefront-eternal-server](https://github.com/centrevilletech/battlefront-eternal-server)
- [battlefront-eternal-master](https://github.com/centrevilletech/battlefront-eternal-master)
- [battlefront-eternal-relay](https://github.com/centrevilletech/battlefront-eternal-relay)

If you are not sure which one is affected, report it here.
